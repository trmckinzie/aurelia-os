# ⚛️ Working Memory

**🔗 Related:** [[Short-Term Memory]], [[Cognitive Load Theory]], [[Baddeley's Model]], [[Chunking]], [[Prefrontal Cortex]], [[Attention]]

---

### 💡 Definition
> A cognitive system with a limited capacity that is responsible for temporarily holding, processing, and manipulating information.

- **The Distinction (STM vs. WM):** While often used interchangeably, cognitive scientists distinguish between them.
    
    - **Short-Term Memory (STM):** A passive storage buffer. (e.g., Remembering a phone number just long enough to dial it).
        
    - **Working Memory (WM):** An active workspace. (e.g., Remembering a phone number _and_ reciting it backward, or doing mental math). It is STM plus the "executive control" to manipulate the data.
        
- **The Metaphor:** If Long-Term Memory is your computer's hard drive (vast, permanent storage), Working Memory is the **RAM** (small, fast, temporary storage used for actively running programs).

### 📝 Key Insight
- **The Ultimate Bottleneck:** Working Memory is severely limited.
    
    - Historically, George Miller (1956) proposed the "Magic Number" of 7 ± 2 items. Modern research (Nelson Cowan) suggests the true capacity is much smaller: roughly **4 ± 1 "chunks"** of information.
        
    - Because the workspace is so small, complex tasks easily overwhelm it. You can't multiply 3,492 by 8,175 in your head—not because you don't understand multiplication, but because your Working Memory drops the carried numbers when it runs out of "slots."
        
- **The Hack (Chunking):** The only way to bypass the 4-item limit is to package information into larger "Chunks" using Long-Term Memory. (e.g., The letters F-B-I-C-I-A-I-R-S take up 9 slots. But if you recognize them as FBI, CIA, IRS, they only take up 3 slots).

### 📐 The Architecture: Baddeley's Model

Developed by Alan Baddeley and Graham Hitch (1974), this is the dominant framework for how the "scratchpad" is organized. It splits WM into specialized subsystems to explain why you can drive (visual) and talk (verbal) at the same time, but you can't read an email and listen to a podcast simultaneously.

1. **The Central Executive:** The "Boss." It doesn't store information itself; it directs attention, coordinates the subsystems, and suppresses irrelevant distractions. (Housed heavily in the Prefrontal Cortex).
    
2. **The Phonological Loop:** The "Inner Ear/Voice." It temporarily holds auditory and verbal information. (e.g., Repeating a password to yourself over and over so you don't forget it).
    
3. **The Visuospatial Sketchpad:** The "Inner Eye." It holds visual and spatial information. (e.g., Visualizing the layout of your house to count the number of windows).
    
4. **The Episodic Buffer:** (Added in 2000). A temporary backup storage that integrates verbal and visual info together and links it to Long-Term Memory to create coherent "episodes" or scenes.
